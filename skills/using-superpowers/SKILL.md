# Using Skills

Skill routing is owned by [ROUTING.md](../ROUTING.md) and follows the current factory step.
Process skills run before implementation skills.
A dispatched lane with an approved brief does not run `brainstorming`'s design gate.
Trivial passes skip the skill pass.
When routing selects a skill, read its `SKILL.md` before acting.
